# v0.1.0

Minecraft Source Kit is a local, agent-guided reference workflow. It inspects a user-supplied client JAR, can prepare decompiled sources, checks supported project version declarations, and can bind and resolve a reference for review. It does not write to the target mod project.

## Commands

- `--version` prints the kit version; `inspect` reads JAR metadata and class headers.
- `verify` checks the local JAR fingerprint against official client metadata. `prepare --verify-official` requires that check to succeed before preparation.
- `check-project` compares supported static declarations; `prepare --project` applies that version gate before preparation.
- `prepare` generates a reference. `--repair` optionally attempts conservative recovery for CFR-reported classes. Standalone `repair` handles an existing kit reference after verifying the original input hash.
- `bind` records a local project binding; `resolve` checks it and reports the reference location.

See the [updating guide](https://github.com/Lightre/minecraft-source-kit/blob/v0.1.0/docs/UPDATING.md) for installation and upgrade instructions. The kit requires Python 3.10+, Git, and a full JDK capable of reading the input bytecode; the Java runtime and compiler must have matching major versions.

## Validation and limits

Full preparation was exercised with Minecraft 26.2 on Windows using Python 3.13 and JDK 25. CI unit tests run on Windows and Linux with Python 3.10 and 3.13; this is not full platform support. The official 1.21.1 client fingerprint verifies successfully, but unnamed-source preparation rejects it. Remapping is not implemented.

Successful generation does not establish decompiled-source correctness, behavioral equivalence, or runtime and Mixin correctness. Decompiled sources are reconstructed and unverified. Review reference reports and validate behavior separately as needed.

## Release process

Stable version tags trigger metadata validation and the four-job unit-test matrix before a draft release is created from these curated notes. Publication remains manual. Existing releases are preserved on reruns.

## Distribution and license

Users supply their own Minecraft JARs. The release bundles no Minecraft materials, generated sources, or binary artifacts. The kit's original code and documentation use `GPL-3.0-only`; external tools and Minecraft materials retain their own licenses and terms.
